feat(compose): expose per-node cwd, readRoots, writeRoots for DAG nodes

- DAG nodes previously inherited the parent session's cwd/roots with no
  override mechanism — parallel subagents in a monorepo needed to operate
  in different package dirs, which was impossible without running separate
  compose calls
- Adds `cwd`, `readRoots`, and `writeRoots` optional fields to each node
  in the compose schema; structural validation (absolute path, no `..`)
  lives in the new `compose-input-parse.ts` module; runtime breadth guards
  (`isTooBroadRoot`, `ungatedSensitiveRoot`) remain in `dag-subagent.ts`
- Extracts `parseComposeInput` into a dedicated file to respect the 350-LOC
  ceiling in `compose-executor.ts`, which was already near the limit before
  this change
- Per-node cwd also fixes crash-recovery manifest accuracy: wave units now
  record the correct working directory per node rather than the parent's cwd
